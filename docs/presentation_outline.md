# Питч-дек трека 1 — продажа + демо

Файл: [`presentation_track1.pptx`](presentation_track1.pptx)  
Пересобрать: `python scripts/build_presentation.py`  
(если файл открыт в PowerPoint — скрипт пишет `presentation_track1_pitch.pptx`)
