## API (для демо без UI)

- `GET /ready` · `GET /health`
- `POST /api/v1/process_call` · `process_call_voice` · `transcribe` · `synthesize`
- `GET /api/v1/calls?phone=` · `/calls/stats?phone=` · `PATCH /calls/{id}?phone=`
- `GET|POST /api/v1/service/settings`
- `GET|PUT|DELETE /routing_rules` · `/scenarios` · `/training_examples`
- `POST /hotline` · `GET /notifications` · `GET /audit` · `GET /stats`

## Запуск демо

```bash
# 1) Ollama
ollama pull qwen2.5:3b && ollama serve
# 2) API
pip install -r requirements.txt
uvicorn backend.main:app --reload --port 8000
# 3) Приложение
python -m frontend.app
# 4) Бот
python -m frontend.tg_bot
```

Проверка: `GET http://127.0.0.1:8000/ready` → `ready=true`, желательно `demo_ready=true`.
